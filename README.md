## [fastfetch](https://github.com/fastfetch-cli/fastfetch)

### install
through winget
```
winget install Fastfetch-cli.Fastfetch
```

### add config

copy the files in [fastfech](fastfetch) into `~/.config/fastfetch` and thats it

you may modify the ascii art to whatever you want by changing the path in [config.jsonc](fastfetch/config.jsonc) (source under logo)

## [kando](https://kando.menu)

### install

through winget
```
winget install KandoMenu.Kando
```

or through [github releases](https://github.com/kando-menu/kando/releases)

## add config

click import menu in settings and select this [file](kando/MyMenu.json)

then download this [theme](https://github.com/kando-menu/menu-themes/blob/main/themes/minecraft) through this [link](https://github.com/kando-menu/menu-themes/releases/latest/download/minecraft.zip) then open settings and on the top click menu themes and click open theme directory and extract the folder you downloaded then copy the folder and paste it in there
